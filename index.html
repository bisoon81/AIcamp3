양방향 신경 제어 랩 BCI

사람에서 기계로(Read) × 기계에서 사람으로(Write)의 폐루프

Feedforward Path (Read)

1. 사람에서 기계로 "생각을 행동으로"

운동 의도 발생 신경신호 디코딩 로봇 의수 제어

대뇌 운동 피질에서 발생한 전기신호를 전극으로 읽어내어, 알고리즘이 "손을 쥐어라"라는 모터 각도 명령으로 실시간 번역합니다.

Feedback Path (Write)

2. 기계에서 사람으로 "기계의 감각을 뇌로"

압력·접촉 감지 자극 패턴 변환 감각 피드백

로봇 손가락 압력 센서의 전압값을 바이페이직(Biphasic) 전기 펄스로 변환하여 대뇌 체감각 피질을 자극, 손끝에 닿는 촉각을 느끼게 합니다.
